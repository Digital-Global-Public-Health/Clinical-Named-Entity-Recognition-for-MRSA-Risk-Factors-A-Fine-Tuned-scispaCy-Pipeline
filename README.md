# Clinical NER for MRSA Risk Factors

Bachelor's thesis project: a scispaCy named-entity recogniser distilled from a
large language model, a rule-based assertion layer, and a lexicon that
aggregates extracted entities into patient-level features.

The pipeline is in [`ner_based/`](ner_based/). Start with
[`ner_based/README.md`](ner_based/README.md) for the eight stages and how to run
them, and [`ner_based/docs/inventory.md`](ner_based/docs/inventory.md) for what
each file is.

Data, models and outputs stay on the Mount Sinai compute enclave and are not in
this repository.
